### memory_floats() = 2n 의 근거

동시에 들고 있는 float:

| 보관물 | 개수 | 포함 |
|---|---|---|
| `r` (현재 점수) | n | ✅ |
| `nr` (다음 점수) | n | ✅ |
| 합계 | **2n** | |

제외한 것:

| 항목 | 이유 |
|---|---|
| `graph` | 두 구현이 똑같이 받는 입력. 문자열과 리스트이며 float 아님 |
| `dead_ends` | 노드 이름(문자열) 목록. float 아님 |
| 스칼라 `beta` `tol` `teleport` `dead_share` `share` `delta` | 약 6개, 그래프 크기와 무관한 고정 개수. 포함 시 2,400 → 약 2,406 |

`s` 배열을 따로 두지 않은 이유: 두면 `r + s + nr = 3n` 이 되어 신고값이 3n 이어야
한다. `nr` 을 `s` 역할로 쓰다가 제자리 변환하면 2n 으로 끝난다.
`nr[v] = beta * nr[v] + teleport` 가 다른 노드 값을 참조하지 않으므로 덮어쓰기 가능.

| | n=1,200 기준 | 3n 으로 신고할 경우 |
|---|---|---|
| 신고값 | 2,400 | 3,600 |
| 메모리 배율 | 600.0배 | 400.0배 |

실측 확인: `bench.py` 가 읽은 `floats held` = **2,400** = 2 × 1,200.
